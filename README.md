# Cyber and AI Security – Research, Columns & Governance Frameworks

This repository contains supporting research notes, governance frameworks, and practical security considerations linked to my published writing on cybersecurity, AI governance, and technology risk.

It is designed for security leaders, CISOs, board advisors, and governance professionals seeking to translate AI regulation and emerging risk into actionable enterprise controls.
